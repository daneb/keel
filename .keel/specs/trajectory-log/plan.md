# Design — trajectory-log

## Approach

A `Trajectory` value owns an open append handle for one run directory. Every
writer in keel takes `&mut Trajectory` rather than reaching for the path, so
there is exactly one place that can write the stream and exactly one place to
enforce the seq invariant. Readers parse line-by-line and never load the file.
