# Design — timeline-clarity

## Approach

The seam is `STAGES` (labels), `renderSpine`/`stageDetail` (the `.stale`
condition and its explanation), and the `.node`/`.node.here`/
`[aria-expanded]` CSS rules — all touched already by SPEC-0006.

1. `STAGES`: relabel `"spec"` to `"spec (G0)"` and `"plan_gate"` to
   `"plan (G1)"`.
2. `renderSpine`: add a `stale(spec)` helper — `spec.stage !== "complete" &&
   approvalStanding(spec, "merge").state === "current"` — and apply a
   `.stale` class to the `merge_approval` and `complete` nodes when it holds.
   `stageDetail` checks the same condition first, for those two keys, and
   prepends an explanation before the existing approval-standing text.
3. CSS: `.node.here` gets a brass fill instead of only an outline;
   `[aria-expanded="true"]` moves to an `--ink` outline instead of reusing
   brass, so the two never look the same regardless of which node(s) they
   land on. `.node.stale` gets a `--blocked`-tinted border, matching the
   existing pass/fail/blocked vocabulary (this is "needs a human to look",
   not a hard failure). Default (pending) `.node` text/border move from
   `--muted` to `color-mix(in srgb, var(--muted) 60%, var(--ink))` for
   contrast. Padding goes from `4px 9px` to `7px 14px` and font-size from
   `11px` to `12px`, matching `.spec-row`'s scale.
