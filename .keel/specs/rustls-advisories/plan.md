# Design — rustls-advisories

## Approach

A single, atomic `Cargo.lock` edit. The seam is the lockfile: the version
requirements in `Cargo.toml` already admit the patched releases (all three
fixes are patch-level), so no manifest change and no source change is needed —
only the resolved versions move.

```
cargo update -p rustls -p rustls-webpki -p webpki-root-certs
```

Verified by dry-run to resolve:

- `rustls` 0.23.45 → 0.23.46 (RUSTSEC-2026-0346/0347/0348/0349)
- `rustls-webpki` 0.103.15 → 0.103.16 (RUSTSEC-2026-0382)
- `webpki-root-certs` 1.0.9 → 1.0.11 (RUSTSEC-2026-0383)

Then `cargo audit`, `cargo build`, `cargo test`, `cargo clippy` confirm the tree
is clean and unbroken, and `git diff` confirms nothing under `src/` or `tests/`
changed. All eight acceptance criteria are facets of this one edit.

## Rollback

`git revert` of the lockfile commit, or `git checkout HEAD -- Cargo.lock`. The
change is a pure dependency resolution; reverting restores the exact prior
versions with no source or behaviour to unwind. The only risk of reverting is
re-introducing the advisories it closed.
